# Rossmann Store Health & Sales Forecasting Platform

> 🚧 **Project Under Development**

This project is currently a work in progress.

The goal is to analyse Rossmann store performance, identify sales patterns, detect underperforming stores, and develop machine learning models to forecast future sales.

The project combines **Python, SQL, Machine Learning, and Power BI** to transform historical sales data into actionable business insights and predictive analytics.

## Project Scope

- **Data Analysis:** Explore historical sales data, identify trends, and investigate key performance drivers.
- **SQL Business Analysis:** Evaluate store health, customer behaviour, sales volatility, and potential causes of underperformance.
- **Machine Learning:** Develop, train, and evaluate predictive models to forecast future store sales.
- **Power BI:** Build interactive dashboards to monitor store performance, highlight potential risks, and visualise forecasting results.

## Project Status

The project is being developed in stages:

- **Data Exploration & Cleaning:** Initial data preparation and exploratory analysis.
- **SQL Business Analysis:** In progress.
- **Machine Learning:** Planned.
- **Power BI Dashboard:** Planned.

The README will be updated as the project progresses, including methodology, model evaluation, key findings, and visualisations.
